# 🩺 Doctor Salary Calculator

A simple Java-based Doctor Salary Calculator that demonstrates the concepts of **inheritance**, **constructors**, **method creation**, and **basic object-oriented programming (OOP)**. The program models doctors and surgeons, calculates a surgeon's total salary based on additional working hours, and displays the final salary.

---

## 📋 Features

- Models doctors using a base `Doctor` class
- Extends the `Doctor` class using a `Surgeon` subclass
- Calculates a surgeon's total salary based on overtime hours
- Demonstrates constructor inheritance using `super()`
- Displays doctor details and updated salary
- Console-based Java application

---

## 📖 Usage

1. Compile and run the program.
2. The application creates a `Surgeon` object with:
   - Doctor ID
   - Base salary
   - Working hours
   - Hourly rate
3. The program calculates the surgeon's total salary by adding overtime earnings to the base salary.
4. The updated doctor details are displayed.
